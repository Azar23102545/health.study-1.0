# Individuell uppgift – Hälsostudie (Del 1)

Detta repo innehåller min individuella uppgift i kursen **Pythonprogrammering och statistisk dataanalys**.

## Innehåll

- `Hälsostudie.del1.ipynb` – Jupyter Notebook med all kod, grafer och analyser för Del 1.
- `data/health_study_dataset.csv` – Dataset som används i analysen.
- `requirements.txt` – Lista över Python-paket och versioner.

## Python-version

Jag har använt **Python 3.13.7**.

## Körning

1. Installera beroenden:

   ```bash
   pip install -r requirements.txt
3. Öppna Hälsostudie.del1.ipynb i VS Code.
4. Kör notebooken med "Restart & Run All".
