# Individuell uppgift - Hälsostudie (Del 1 & Del 2)

Detta repo innehåller båda delarna av min individuella uppgift i kursen  
**Pythonprogrammering och statistisk dataanalys**.

Syftet är att analysera ett hälsodatat och göra både enklare och lite mer fördjupade analyser
med hjälp av Python, Jupyter Notebook och några olika statistiska metoder.

## Innehåll

- `Hälsostudie.del1.ipynb` – Notebook för Del 1 **beskrivande statistik, grafer, simulering, konfidensintervall, hypotesprövning**.
- `Hälsostudie.del2.ipynb` – Notebook för Del 2 **funktioner, modul, klass, regression, utökad analys**.
- `health_analysis.py` – Modul med funktioner och klassen **HealthAnalyzer** som används i Del 2.
- `data/health_study_dataset.csv` – Dataset som analyseras.
- `requirements.txt` – Lista över Python paket och versioner.
- `.gitignore` – Filer och mappar som ignoreras av **Git.**

## Python-version

Jag har använt **Python 3.13.7**.

## Körning

1. Installera beroenden:

   ```bash
   pip install -r requirements.txt
3. Öppna Hälsostudie.del1.ipynb och Hälsostudie.del2.ipynb i VS Code.
4. Kör notebooken med "Restart & Run All" för att se till att allt funkar från början till slut.
